# Política de segurança

Não abra issues públicas para relatar vulnerabilidades, tokens expostos,
credenciais vazadas ou outros dados sensíveis. Use o contato privado indicado
no perfil do mantenedor ou o canal de segurança disponível na organização.

Ao reportar uma falha, informe o impacto, os passos mínimos para reproduzir e
quais versões foram afetadas. Nunca inclua senhas, tokens, cookies, chaves ou
dados pessoais.
